# 🎮 НейроКвест + НейроГонка 3D

Образовательные проекты по информатике об **основах искусственного интеллекта** в игровой форме.

## Игры в репозитории

| Игра | Папка | Суть |
|------|-------|------|
| 🕹️ **НейроКвест** (2D) | корень (`index.html`) | 5 уровней-задач: викторина об ИИ, дерево решений, поиск A*, распознавание цифр нейросетью, обучение с подкреплением |
| 🏎️ **НейроГонка 3D** | `game3d/` | Экшен на Three.js: неоновый киберраннер собирает данные, проходит лабиринты решений, трассы A*, патрули зрения и RL-арену |

## 🚀 Запуск

Локально: открой `index.html` (2D) или `game3d/index.html` (3D) в браузере, либо:

```bash
python3 -m http.server 8000   # 2D → http://localhost:8000 , 3D → http://localhost:8000/game3d/
```

GitHub Pages: включи в **Settings → Pages** ветку `main` / корень — тогда 2D-игра откроется по ссылке `https://ditrops.github.io/TestQWEN/`, а 3D — `/game3d/`.

## 🧠 Темы ИИ, которые раскрываются

1. **Что такое ИИ** — тест Тьюринга, узкий vs сильный ИИ
2. **Машинное обучение** — обучение с учителем, признаки, классификация
3. **Деревья решений** — правила ЕСЛИ/ТО
4. **Поиск и эвристики** — алгоритм A*, манхэттенское расстояние
5. **Нейронные сети** — вектор признаков, softmax, вероятности
6. **Обучение с подкреплением** — агент, награда, среда, стратегия

## 💡 Идеи для защиты проекта

- Покажи оба режима: 2D — «класс», 3D — «вау-эффект».
- На каждом уровне объясни, какой раздел ИИ за ним стоит.
- Расскажи, что игры работают без сервера: вся логика на чистом JS + Three.js.
