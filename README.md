# Мой первый проект

Добро пожаловать! Это репозиторий для изучения Git и GitHub.

## Полезные команды Git

| Команда | Что делает |
|---|---|
| `git status` | Показывает состояние файлов |
| `git add <файл>` | Добавляет файл в индекс |
| `git commit -m "описание"` | Сохраняет изменения |
| `git log` | История коммитов |
| `git pull` | Скачивает изменения с GitHub |
| `git push` | Отправляет изменения на GitHub |

## Как отправить проект на GitHub

1. Создай репозиторий на [github.com/new](https://github.com/new)
2. Подключи его: `git remote add origin https://github.com/ЛОГИН/РЕПОЗИТОРИЙ.git`
3. Отправь: `git push -u origin main`
