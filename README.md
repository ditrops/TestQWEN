# 🧠 НейроКвест — игра об основах искусственного интеллекта

Учебный проект по информатике: браузерная игра-квест, в которой игрок за 5 уровней
осваивает базовые понятия ИИ и машинного обучения. Работает **полностью офлайн** —
нужен только браузер (HTML + CSS + чистый JavaScript, без библиотек и сборки).

## 🚀 Как запустить

Просто открой файл `game/index.html` в любом браузере (двойной клик).

Или через локальный сервер:

```bash
cd game
python3 -m http.server 8000
# открыть http://localhost:8000
```

## 🎮 Уровни игры

| № | Уровень | Тема ИИ | Механика |
|---|---------|---------|----------|
| 1 | 🤖 Что такое ИИ? | Тест Тьюринга, узкий/сильный ИИ, ML vs классическое программирование | Викторина с пояснениями после каждого ответа |
| 2 | 🌳 Дерево решений | Обучение с учителем, признаки, правила классификации | Собираешь правила «ЕСЛИ… ТО…» как в м/ф «MACHINE LEARNING» |
| 3 | 🔍 Поиск A* | Поисковые алгоритмы, стоимость, эвристика (манхэттенское расстояние) | Прокладываешь путь робота по карте с ценами клеток |
| 4 | 👁️ Нейронная сеть | Пиксели → вектор признаков → вероятности классов (softmax-подобный вывод) | Рисуешь цифру 8×8, «нейросеть» угадывает её и показывает вероятности |
| 5 | 🎮 Обучение агента | Обучение с подкреплением: награда, штраф, политика | Собираешь звёзды и избегаешь ям 5 раундов |

## ⭐ Система прогресса

- За каждый уровень можно получить от 1 до 3 звёзд (максимум 15).
- Следующий уровень открывается после прохождения предыдущего.
- Прогресс сохраняется в `localStorage` браузера.
- В финале — звание («Начинающий исследователь» → «Архитектор ИИ») и интересный факт об ИИ.

## 📁 Структура проекта

```
game/
├── index.html   — разметка всех экранов и уровней
├── style.css    — оформление (тёмная «космическая» тема, адаптив под телефон)
└── app.js       — логика: навигация, прогресс, все 5 мини-игр
```

## 🧩 Что внутри app.js

- `Store` — сохранение/загрузка прогресса (localStorage)
- `UI`, `Menu`, `Game` — экраны, меню, переходы, оверлей результатов
- `Quiz` — движок викторины уровня 1
- `DecisionTreeGame` — конструктор правил и проверка классификации (уровень 2)
- `AstarGame` — карта, клики по клеткам, подсчёт стоимости пути (уровень 3)
- `NNGame` — рисовалка 8×8 + «распознаватель»: признаки (ширина, высота,
  замкнутые области flood-fill, масса центра) → оценки → softmax-вероятности (уровень 4)
- `RLGame` — сетка 5×5 со звездой/ямой и наградой за шаги (уровень 5)

## 💡 Идеи для защиты проекта

- Показать разницу «правила пишет человек» (уровень 2 вручную) vs «правила учится из данных».
- Объяснить эвристику h на уровне 3: почему A* быстрее простого перебора.
- На уровне 4 продемонстрировать, как одна «дырка» в рисунке отличает 0 от 7 — это и есть признак.
- На уровне 5 — принцип награды/штрафа, на котором обучены AlphaGo и ChatGPT (RLHF).
